# Referências dos ícones

Capas oficiais digitalizadas, usadas a pedido do proprietário para seu aplicativo privado:

- Emerald: https://www.pokemondungeon.com/media-downloads/box-art/pokemon-emerald — `emerald.jpg`.
- FireRed: https://www.pokemondungeon.com/media-downloads/box-art/pokemon-firered — `firered.jpg`.

O ícone Emerald foi criado com imagegen a partir da referência e copiado para `drawable-nodpi/icon_emerald.png`. A geração FireRed foi recusada. Para essa opção foi usada a arte oficial de Charizard, sem edição do arquivo, de https://www.pokemon.com/static-assets/content-assets/cms2/img/pokedex/full/006.png (`charizard-official.png`). O Android a exibe sobre um fundo rubi/âmbar através de `drawable/icon_firered.xml` e `drawable-nodpi/art_firered.png`. As imagens não são apresentadas como arte original do projeto nem como assets livres. A opção GBA é um vetor genérico do aplicativo.

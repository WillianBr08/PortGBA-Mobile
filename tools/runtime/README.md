# Tk local para o gerador Linux x86_64

Tcl 8.6.16 e Tk 8.6 da distribuição Arch Linux, carregados apenas pelo launcher `portar-gba.sh`. Fontes e licenças upstream: https://www.tcl-lang.org/ e `usr/share/licenses/{tcl,tk}`. Os arquivos foram extraídos dos pacotes oficiais de distribuição; não substituem bibliotecas do sistema. Em outras distribuições/arquiteturas pode-se usar o Python/Tkinter local e executar `python3 tools/portar_gba.py` diretamente.
